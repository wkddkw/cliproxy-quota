# Provider marks

GPT / OpenAI and Claude vector marks are sourced from the
[CLIProxyAPI provider assets](https://github.com/router-for-me/CLIProxyAPI/tree/main/assets/logo).
The Grok mark is from the [management UI icon assets](https://github.com/router-for-me/Cli-Proxy-API-Management-Center/blob/main/src/assets/icons/grok.svg).
They identify the corresponding provider and do not imply affiliation.

PNG variants are rendered from the included SVGs with `rsvg-convert -w 144 -h 144`.
The same marks are used in the App, Android AppWidget and iOS WidgetKit extension.
