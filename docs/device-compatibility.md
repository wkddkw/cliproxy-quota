# 手机与桌面小组件兼容性

最后更新：2026-10-02，App v0.1.2。

手机品牌和“小组件能否添加”不能一一对应：是否支持由 Android 版本、系统桌面应用及其版本、所在用户空间决定。换用第三方桌面也会改变结果。

| 品牌 / 机型 | 桌面系统 | v0.1.2 的接入方式 | 真机验证状态 |
| --- | --- | --- | --- |
| 一加 13T | ColorOS 16（用户提供） | App 设置 → 添加桌面小组件；不接受请求时寻找 Android 小组件入口 | 用户反馈 v0.1.0 卡片中心找不到；用户反馈 v0.1.1 显示支持直接添加，但按钮无反应；v0.1.2 反馈与诊断改进待回测 |
| 其他一加 / OPPO | ColorOS 等，依实际系统为准 | 标准 Android AppWidget + 系统固定入口 | 未逐机型验证 |
| vivo / iQOO | OriginOS / Funtouch OS 等 | 标准 Android AppWidget；厂商特色卡片中心是否列出需实测 | 未逐机型验证 |
| 小米 / Redmi | HyperOS / MIUI 等 | 标准 Android AppWidget；桌面编辑中的普通 Android 小组件入口 | 未逐机型验证 |

此表是接入方式与验证状态表，**不是已经实测兼容全部机型的承诺**。没有实测证据时不列为“已验证支持”。

## 不在卡片中心显示时

打开 App 的设置页，找到「桌面小组件」。页面会在本机调用系统能力检查，并显示手机型号和当前桌面是否支持直接添加。这些信息不上传。

- 支持直接添加：点击按钮，按系统弹窗确认。请求被接受并不代表已经添加，仍需要完成系统确认。
- 不支持直接添加：长按桌面空白处，寻找普通“小组件”或“Android 小组件”。各系统版本的菜单名称和位置不同，可能与厂商特色卡片入口分开。
- 系统桌面确实没有暴露标准小组件入口：该桌面只能使用 App，或使用支持标准小组件的桌面应用。

这一版实现标准 Android AppWidget 和 iOS WidgetKit，没有实现各厂商的私有特色卡片协议。仅提供编译结果不能替代真机桌面兼容测试。

## 更新安装

v0.1.0 使用临时 CI 开发签名；v0.1.1 起使用固定的预览签名。第一次从 v0.1.0 升级需先卸载旧版，再安装 v0.1.1，并重新输入地址和管理密钥。之后同一固定签名的预览版可覆盖升级。私钥只保存在该仓库的加密 GitHub Secrets 中，不提交到公开代码。

## v0.1.2 诊断版

按钮在桌面报告不支持直接固定时也可点击，会显示原因和手动添加说明。支持直接固定时，等待系统确认，并检查实际创建的小组件 ID；12 秒内没有新实例会说明尚未检测到添加。可复制本机诊断信息（设备、Android API、桌面包名、组件是否注册、已创建数量、请求结果），不包含服务器地址或管理密钥。这些能力还不能证明 ColorOS 16 真机已添加成功。

当桌面报告支持却没有后续反馈时，本版将原生系统调用放在后台任务队列，并在 8 秒未返回时提示超时，避免无限等待。超时是诊断结果，不能单凭它判断 ColorOS 的根本原因。
